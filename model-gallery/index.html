Come funziona l'archivio

Le revisioni 05, 06, 15 e 16b sono identificate con commit verificati. La pagina cerca inoltre tutti i checkpoint della mesh presenti nei branch pubblici di Neliel e li aggiunge ai menu, anche in futuro. I commit intermedi possono avere nomi descrittivi invece di un numero di revisione: non viene inventata una numerazione. Selezionando una versione viene sempre caricata la mesh salvata in quel preciso commit, non il file corrente di un altro branch.

Il confronto applica lo stesso rendering cel-shaded a entrambe le mesh. Costume studio usa un costume viola temporaneo applicato alla superficie del corpo in tutte le revisioni. Pelle neutra nasconde la texture dei vestiti e mostra la geometria anatomica realmente modellata senza inventare dettagli mancanti. Capelli lunghi nasconde coda e ciocche laterali. Queste modalità non modificano i file GLB originali.

Le versioni nuove nei branch GitHub vengono trovate con “Aggiorna versioni”. Puoi anche inserire un nuovo branch o commit senza cambiare il codice. Le scelte A/B sono ricordate su questo dispositivo.

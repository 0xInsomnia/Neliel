# Line v2 — Neliel rebuilt on a new base (branch `neliel-v2`)

Decided with the user on 15 November 2026: everything is redone from the
technical sheet ("Scheda Tecnica Modello 3D", private) on a new body base,
except the skeleton, which is kept from revision 15 (`nelielclaude`).

Base: "Anime Base Female" by David Onizaki, CC BY (see `assets/v2/CREDITS.md`).
Checked before use: the body mesh is modelled from a plane, with plain English
vertex groups and no rig or game data; the author's file also carried a toon
shader copied from game models (MMD material data and miHoYo notes attached to
the materials). Only the body and its shape keys are kept.

Tools (`tools/v2/`):
- `import_base.py` (needs `pip install bpy`): author's .blend -> clean
  `assets/v2/base-onizaki.glb`, 5,518 vertices, 28 shape keys.
- `tpose_base.py` (NumPy): shape-key mix baked (bust 1, hips .8, thighs 1,
  calves .6, upper arms .3), turned to face -Z, arms raised 36.6 degrees about
  the shoulder by a smooth rotation field (cone around the arm axis; legs,
  trunk, breast and neck excluded).
